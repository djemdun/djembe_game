# ジャンベ音ゲー

ブラウザで遊べるジャンベのリズムゲームです。リズム練習にも使えます。スマホでも動きます。

## 遊び方
1. 「タップして開始」を押すと、1小節ぶんのカウントイン(拍音)のあと、上からノーツが降ってきます。
2. ノーツが下の白い線(判定ライン)に重なるタイミングで、そのレーンを叩きます。

6レーンは左から **左高・左中・左低・右低・右中・右高** です。

| 操作 | 内容 |
| --- | --- |
| キーボード | `A` `S` `D` = 左手(高・中・低)／ `J` `K` `L` = 右手(低・中・高) |
| タップ | 画面のレーンを直接タップ(マルチタッチ可。複数の指で同時に叩けます) |

判定は音ごとに PERFECT / GOOD / MISSED。曲の最後に、曲全体の評価(PERFECT / GREAT / GOOD / TRY AGAIN)と各判定の数が出ます。

## 設定(開始画面・結果画面)
- **拍音**: ON/OFF と音量。小節の頭は高く強い音で鳴ります。
- **拍線**: ノーツの下に拍の横線を表示(小節の頭は濃い線)。
- **速さ**: 0.5〜1.5倍(0.05刻み)。横に「×0.85 (BPM 110)」のように実際のBPMが出ます。
- **判定オフセット**: 叩くのが遅れて判定される/音が遅れて聞こえるなら＋、早いなら−。プレイ中に出る「+23ms」の平均が0に近づくように調整してください。

設定はこの端末のブラウザに保存されます。

## URLパラメータ
- `?speed=0.75` 速さ倍率を指定(0.1〜4)。指定すると速さスライダーは無効になります。
- `?chart=<曲id>` 曲を指定(`songs/index.json` の一覧にあるもの)。`?chart=easy` は動作確認用の易しい譜面です。

## 開発者向け
ビルドは不要です(素のJavaScript / ES Modules)。`file://` では動かないので、ローカルサーバーで開きます。

```
python3 -m http.server 8000   # http://localhost:8000/
npm test                      # 単体テスト(Node標準の node:test。追加パッケージ不要)
```

仕様・構成・設計判断は [CLAUDE.md](CLAUDE.md) にあります。曲は `songs/<id>.txt`(文字譜)と `songs/index.json`(一覧と既定曲)で管理します。
