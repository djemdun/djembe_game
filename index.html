    更新されない場合(画面が古い・エラーが出る)

    ブラウザに古いデータが残っています。お使いの端末の手順で消してから、一番下のボタンで読み込み直してください。

    iPhone / iPad(Safari)

    1. 「設定」→「アプリ」→「Safari」→「詳細」→「Webサイトデータ」(iOS 17 以前は「設定」→「Safari」→「詳細」)
    2. 検索欄に github と入れ、出てきた github.io を左にスワイプして削除
    3. 見つからなければ、「Safari」の画面の「履歴とWebサイトデータを消去」

    Android(Chrome)

    1. 右上の「︙」→「履歴」→「閲覧履歴データを削除」
    2. 期間は「全期間」、「キャッシュされた画像とファイル」にチェックして削除

    パソコン(Chrome / Edge / Firefox)

    1. Ctrl + Shift + Delete(Mac は Cmd + Shift + Delete)
    2. 期間は「全期間」、「キャッシュ(キャッシュされた画像とファイル)」にチェックして削除
    3. Mac の Safari は「Safari」→「設定」→「プライバシー」→「Webサイトデータを管理」

    github.io のデータを消すと、他の GitHub Pages のサイトの保存データも消えます。このゲームの設定(判定オフセットなど)も初期化されるので、読み込み直した後に入れ直してください。
